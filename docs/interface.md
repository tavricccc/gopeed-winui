# Main window
Mode: Operate. User delegates design; native WinUI grammar is binding. Code-led implementation using platform controls, not image-generated UI.

## Direction contract
THESIS: Downloads are a work queue. The main surface exposes state, progress and the next action without dashboard metrics or decorative cards.
OWN-WORLD: Windows Fluent controls, system theme and typography, one system accent. List rows remain flat, with subtle separators and clear selected state. Native command bar and context menus.
STORY: Add a link, inspect its files and destination, start it, monitor progress, pause or resume, open the result. Errors are inline and actionable.
FIRST VIEWPORT: Title bar, top navigation for downloads/extensions/settings; download page header with Add and search; status filter, virtualized list; selected task details at right on wide windows, below on narrow windows; summary at bottom.
FORM: Native transfer queue, user-pinned Windows grammar. Seed d3f55cc7. Grounded alternatives: Explorer list, Settings navigation, compact utility, transfer queue, mail master-detail, Store library, Terminal sessions. Challenger materials are declined where they conflict with native WinUI; retain crisp state contrast and disciplined information density.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
