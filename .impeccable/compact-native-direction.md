# 原生下載器介面方向

模式：Operate。平台：Windows desktop / WinUI 3。

使用者指定 `C:\Users\Tavric\projects\downlism` 的實際 XAML 與視窗程式碼為主要視覺依據；AB Download Manager 的實際清單與下載視窗程式碼、IDM 的操作方式為補充。0.3.0 的大標題、三列下載項目、永久詳情欄與固定大進度窗是這次替換的對象。

- 單列下載清單，44 DIP 最小列高；檔名、傳輸量、進度／狀態、速度與操作在同一列。
- 原生 CommandBar、ListView、ComboBox 與系統字型／主題資源；沒有網頁 hero、卡片層疊或自訂装飾性動畫。
- 每列第一個按鈕採重點色，操作依狀態為暫停、繼續、重試或開啟檔案。資料夾與移除放在其後。
- 主視窗預設 960×560 DIP；窄視窗隱藏大小欄保留檔名。設定與擴充功能使用原生頁面返回入口。
- 下載確認是獨立置頂視窗，560 DIP 內容寬；常用欄位並排，進階選項收合，依實際內容調整高度。確認前不建立任務。
- 開始後解除置頂，進度內容寬 520 DIP，僅顯示檔名、位置、傳輸／速度／剩餘時間、狀態與操作。来源網址在浮出層中。完成後第一個按鈕為開啟檔案。
- 保留批次、來源更新、Torrent 檔案選取、分類、代理、解壓、設定及擴充功能入口。
- 使用者介面只包含使用者操作所需的文字；設計與開發決策留在本文件。

視覺驗證：實際 Windows 視窗的淺色主清單、最小寬度、確認、進階選項、下載中／暫停／完成、深色與設定／擴充功能。截圖必須能顯示當前介面；鎖定桌面的空白 PrintWindow 圖不算證據。

原生 XAML 不執行 HTML/CSS detector。沒有圖像 mockup；指定參考程式碼就是視覺依據。
