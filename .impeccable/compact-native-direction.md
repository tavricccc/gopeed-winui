# 原生下載器介面方向

模式：Operate。平台：Windows desktop / WinUI 3。版本：0.5.0。

參考 Downlism 的實際 `MainWindow.xaml`、`App.xaml`、`NewDownloadWindow.xaml` 及視窗內容量測程式碼。使用者要求清楚的字型、留白與原生外框；不能把精簡做成擁擠。

- 明確指定 Segoe UI Variable 與 Microsoft JhengHei UI，標題、檔名、內文與辅助文字有不同層級。
- 主視窗預設 1120×640 DIP，單列最小高 56 DIP。檔名有主要空間，欄位間距 16 DIP；窄視窗隱藏大小欄。
- 工具列只放新增、貼上、選取暫停／繼續。設定在右上，其餘功能在更多選項與內容功能表。
- 確認與進度窗同為 660 DIP 內容寬，依可見內容和實際底部操作區量測高度；展開內容後保持在工作區內。
- 使用 WinUI TitleBar、Mica、Windows 原生圓角及系統細框，不另包一層裝飾性外框。
- 確認期間置頂，開始後解除置頂。表單標籤與欄位並排，選項預設收合。
- 進度按檔名與位置、傳輸資訊、底部操作分區；沒有 HTTP 協定標籤。完成後第一個主要操作為開啟檔案。
- 來源與關閉偏好在更多選項內，不塞進主要按鈕列。保留批次、Torrent、分類、來源更新、代理、解壓與擴充功能入口。

設計與開發決策留在文件，不放入產品文字。原生 XAML 不執行 HTML/CSS detector。
