# Gopeed Native

WinUI 3 Windows frontend for the Gopeed download engine. Traditional Chinese, native controls, independent background engine. This is an independent project, not an official Gopeed release.

## Source layout
- `upstream/`: pinned Gopeed 1.9.3 submodule (GPL-3.0).
- `core/`: headless API host; no Flutter dependency.
- `src/`: native frontend and API client.
- `scripts/`: build, packaging and validation.

Development and verification instructions are completed alongside the implementation.
